## Po obecnych lekcjach

Uczeń powinien umieć:

- wyjaśnić różnicę między klasą i obiektem,
- tworzyć obiekty,
- korzystać z pól, metod, konstruktorów i właściwości,
- rozróżniać dane obiektu i dane `static`,
- pracować z kilkoma obiektami tej samej klasy,
- rozpoznać sytuację, w której dwie zmienne odnoszą się do tego samego obiektu.

## Planowane rozwinięcie działu

- tablice obiektów,
- listy obiektów,
- obiekt jako element innego obiektu,
- ćwiczenia podsumowujące OOP.
