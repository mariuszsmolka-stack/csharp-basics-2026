# 09 - Testowanie i asercje

W tym dziale uczeń poznaje podstawy sprawdzania poprawności programu za pomocą asercji oraz prostych testów jednostkowych.

Testowanie pomaga wykrywać błędy wcześniej. Dzięki asercjom i testom można sprawdzić, czy metoda zwraca taki wynik, jakiego oczekujemy.

## Po tym dziale

Uczeń powinien umieć:

- wyjaśnić, czym jest asercja,
- zastosować `Debug.Assert` w zwykłym programie konsolowym,
- odróżnić asercję od instrukcji `if`,
- odróżnić asercję od walidacji danych użytkownika,
- przygotować prosty test jednostkowy w MSTest,
- dobrać kilka sensownych przypadków testowych dla jednej metody.
