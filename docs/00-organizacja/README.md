# Organizacja kursu

## Cel kursu

Kurs wprowadza początkującego ucznia w programowanie konsolowe w języku C#. Materiały są ułożone od podstaw składni do pierwszych zagadnień programowania obiektowego.

## Jak korzystać z kursu

Lekcje są ułożone od najprostszych tematów do trudniejszych. Najlepiej realizować je po kolei, ponieważ kolejne materiały korzystają z wcześniej wprowadzonych zagadnień.

- Przepisuj przykłady do projektu konsolowego w Visual Studio.
- Uruchamiaj program po każdej istotnej zmianie.
- Analizuj wyniki działania kodu.
- Wykonuj ćwiczenia znajdujące się na końcu lekcji.
- Wracaj do wcześniejszych materiałów, jeżeli nowe zagadnienie wykorzystuje nieznaną konstrukcję.
