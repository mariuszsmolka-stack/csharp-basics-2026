## Po tym dziale

Uczeń powinien umieć:

- pracować z tablicami wielowymiarowymi,
- przechowywać dane w `List<int>` i `List<string>`,
- wybrać między tablicą a listą,
- przekazywać dane do metod przez wartość oraz korzystać z `ref` i `out`,
- bezpiecznie wczytywać dane za pomocą `TryParse`,
- grupować i zwracać kilka wartości za pomocą krotek,
- analizować, dzielić i łączyć napisy,
- generować liczby losowe za pomocą klasy `Random`.
